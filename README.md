# 店舗間 貸し借り台帳

飲食店の複数店舗間で発生する物品の貸し借りを、グループチャットの平文から
URL一本のWeb台帳に置き換えた実装の記録です。

**公開ページ: https://tokoyuru8.github.io/store-lending-ledger/**

## 概要

| 項目 | 内容 |
|---|---|
| 制作 | 2026年8月 / 1日 |
| 構成 | Google Apps Script + スプレッドシート |
| 配布 | 公開URL・利用者のログイン不要 |
| 運用費 | 0円 |

## 扱っている論点

- 導入の摩擦を最小化する設計判断（認証なし・事前登録なし・既存運用との並走）
- 日本語の表記ゆれを吸収する名寄せの多層構成（正規化キー / ローマ字照合 / 接頭接尾語の除去 / 別名の学習）
- 機械が自動で判断する範囲と、人に確認を残す範囲の線引き

## 注記

掲載している画面写真はサンプルデータによるもので、店名・担当者名はすべて仮名です。
稼働中の台帳のURLは掲載していません。
